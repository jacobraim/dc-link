# DC Link — Washingtonian visual build

A separate visual branch of the DC Link prototype. It keeps the existing gameplay and dated `puzzles.js` structure while introducing a distinct Washingtonian presentation.

## What changed

- Sage, gold, navy, and burgundy difficulty palette
- Soft solved cards with dark text, borders, accent rails, and shadows
- More editorial typography and spacing
- Raised neutral tiles with clearer selected states
- Lock/bounce animation before a correct group settles into place
- Refined start, game, reveal, and results screens

## Run and deploy

Open `index.html` locally or upload all files to the root of the GitHub repository connected to Vercel. No build command is required.
